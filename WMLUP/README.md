# WMLUP - Windows Mobile Legacy Update Platform

This is the main hub for the Windows Mobile Legacy Update Platform project. It serves as a central portal linking to the research repositories for various legacy Windows Mobile platforms.

## Overview
WMLUP is a research-grade, multi-platform framework for exploring and restoring update systems on old Windows Mobile devices.

### Platforms
- **[W10MLUP](../W10MLUP/)**: Windows 10 Mobile, FE3 update system research.
- **[W81MLUP](../W81MLUP/)**: Windows Phone 8 / 8.1, update metadata and tools research.
- **[W7MLUP](../W7MLUP/)**: Windows Phone 7, Zune-based update system exploration.

## Structure
Each platform has its own repository to allow independent growth, documentation, and separation of responsibilities. This hub provides a unified landing page and shared design language.

## Design
The project uses a retro MSN / Windows 2003 inspired design to match the era of the devices being researched.
