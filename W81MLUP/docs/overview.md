# W81MLUP Platform Overview

## Research Focus
W81MLUP focuses on Windows Phone 8 and 8.1 update metadata and tools. This era used a Windows Update style system for discovery and delivery.

## Status
- **Metadata Parser**: Functional alpha.
- **Update Simulation**: Researching device-side registries.
- **CAB Discovery**: Working on catalog archiving.

## Known Issues
- Certificates for some packages have expired, causing installation issues on live devices.
- Many catalog servers are inaccessible.
