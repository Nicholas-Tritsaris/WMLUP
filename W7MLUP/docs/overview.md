# W7MLUP Platform Overview

## Research Focus
W7MLUP focuses on Windows Phone 7 update mechanisms, which primarily depend on the Zune software on a PC.

## Status
- **Zune Communication**: Exploring USB sync protocols.
- **Update Metadata**: Investigating catalog structure.
- **Tools**: Early-stage protocol sniffers.

## Known Issues
- Zune software is deprecated and server-side checks are disabled.
- Many WP7 devices cannot be updated without a patched host environment.
